Open Source

Built with the
community

Core drivers and tools are open source. FPGA firmware stays closed — your hardware investment stays protected.

lidarforge-ros2C++

Full ROS2 driver package for all LF-series sensors. Publishes PointCloud2, LaserScan, and IMU topics out of the box.

⭐ MIT License🔀 ROS2 Humble
lidarforge-sdkPython / C

Low-level SDK interface layer for custom integrations. UDP packet parser, calibration tools, and data recording utilities.

⭐ Apache 2.0🔀 Linux / macOS
pointcloud-toolsPython

Point cloud processing examples — ground segmentation, object detection, SLAM integration with KISS-ICP and Fast-LIO2.

⭐ MIT License🔀 Open3D / PCL
lf-drone-examplesPython

Ready-to-run code examples for drone obstacle avoidance, terrain following, and precision landing using PX4 and ArduPilot.

⭐ MIT License🔀 PX4 / ArduPilot
