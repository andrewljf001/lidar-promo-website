## 🏘️ 社区策略决策

### 核心方向
- **自己的网站是社区根据地**，其他平台（Hackaday / Reddit 等）只作为推广引流入口
- 社区论坛：**Discourse**，部署在自有独立服务器，完全自主可控
- 以开源撬动技术社区关注，吸引技术大拿

### ✅ 开源内容清单（公开，促进销售）

| 内容 | 说明 |
|------|------|
| ROS 驱动包 | 买了硬件才能完整使用，开源反而促进销售 |
| 上位机 SDK 接口层 | 方便开发者快速集成 |
| 点云数据处理示例代码 | 降低开发门槛 |
| 应用案例代码 | 无人机避障、SLAM 示例等 |

### 🔒 闭源内容（核心竞争力，永不开放）

| 内容 | 说明 |
|------|------|
| FPGA 固件 | 核心算法所在，绝对壁垒 |
| Sony IMX459 驱动调教参数 | 关键性能差异来源 |
| 硬件原理图 | 除非后续有意销售 PCB 设计 |

### 冷启动路径

| 阶段 | 行动 | 说明 |

| 第二步 | 开源 ROS 驱动 / SDK，吸引技术大拿 | GitHub 开源仓库 |
| 第三步 | 引导用户回到自己网站的 Discourse 社区 | 自有服务器部署，完全自主 |
