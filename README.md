# lidar-promo-website

## 项目概述
本仓库用于开发 **激光雷达 B2B 推广网站**，面向海外买家，支持线下汇款询价。

## 网站信息

| 字段 | 内容 |
|------|------|
| 项目类型 | B2B 静态推广网站 |
| 目标受众 | 海外激光雷达采购商 |
| 询价方式 | 线下汇款询价（表单 + 邮件）|
| 仓库地址 | https://github.com/andrewljf001/lidar-promo-website |
